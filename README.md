# 方寸 · Tactora

项目仓库：[ZhuTango/tactora](https://github.com/ZhuTango/tactora)。面向 macOS 的轻量工具合集，后续工具统一接入菜单栏与设置。

原生 Swift / AppKit macOS 菜单栏工具，包含多屏桌面背景、剪贴板历史和统一设置。当前版本 **1.17.0**，支持 macOS 13 及以上。

无第三方运行时依赖，无常驻网页引擎；应用不联网，数据仅保存在本机。

## 发布管理

`1.x.0` 正式发布，修订版本 `1.x.y`（y > 0）仅推送代码。版本流程见 [发布规则](RELEASING.md)，版本变更见 [更新日志](CHANGELOG.md)。

## 功能

### 桌面背景

- 每个显示器独立选择图片、视频或混合列表，按显示器 UUID 保存配置。
- 菜单栏只显示已连接的显示器，提供选择文件、下一项、轮换间隔、停止/恢复和清除配置。
- 断开显示器后保留配置，重新连接时恢复。
- 支持自动轮换，间隔可设为 10–86400 秒。
- 统一设置中的画质选项适用于所有屏幕：原画（默认）、均衡（1440p/30 fps）、低耗（1080p/30 fps）。
- 支持低内存循环与无缝循环；桌面被完全遮挡时可自动暂停，休眠和低电量模式下暂停播放。
- 同一视频及播放配置共享播放器；视频资源消耗仍取决于分辨率、帧率、编码和显示器数量。

### 剪贴板

- 保存文字、图片和文件引用；图片保存本地副本，文件不复制原文件。
- 搜索支持中文、拼音、首字母和匹配高亮。
- 支持固定、分组、别名和当前会话内撤销最近一次删除。
- 保留时间可选 7 / 30 天，最多 1000 条记录，图片缓存上限 2560 MiB。
- 最多固定 200 条；固定项不自动过期，手动删除或清空仍会移除。
- 可配置全局呼出快捷键；打开后直接输入搜索。
- 回车或双击复制，可选自动粘贴到原应用；自动粘贴需要辅助功能权限。
- 横向滚动与懒加载，非文字编辑状态下可按 Backspace 删除。

### 文本快捷处理

- 从菜单栏打开独立面板，左侧粘贴/输入原文，右侧预览结果；只在点击“复制结果”时写入剪贴板。
- 支持去整段文字首尾空白、用空格合并换行、去除空行、按行精确去重（保留首次顺序）、转大写和转小写。
- 每次处理一种操作，切换操作始终基于原文，不叠加修改；支持 Unicode、CRLF / CR / LF 换行。
- 全部本地处理，输入上限 1 MB，编辑时延迟更新预览；关闭或停用后清空面板内容，不保存文本。
- 通用设置中可独立停用；停用后隐藏菜单入口并关闭面板。可用 `--text-tools` 启动参数直接打开。

### 截图识字 OCR

- 针对常见字体的 `⌘`、`⇧` 快捷键符号补充图形识别；仅对高匹配且与按键相邻的符号修正，特殊字体、模糊图片仍可能识别不准。
- 独立工具开关，默认快捷键 `⌘⇧D`，可在「设置 → 截图识字」录制、清除或恢复默认。
- 框选后通过系统 Vision 在本地识别中英文并复制，默认保留换行；可关闭换行或选择识别后打开剪贴板列表。
- 只有剪贴板记录开启时才保存历史并标记「截图识字」；关闭记录仍能识字复制，不自动启用历史。
- 图片历史卡片右键「提取文字」复用同一识别能力，无需重复截图。
- 首次框选需要 macOS 屏幕录制权限；图片历史识别不需要屏幕录制权限。按 Esc 取消或未识别到文字时保留原剪贴板。
- 不联网、不常驻采集屏幕。临时截图存于私有目录并在读取后删除，识别任务结束释放图像；输入上限 40 MB，识别图像最长边限制 4096 像素。

### 应用切换

- 在「设置 → 应用切换」中搜索已安装应用，配置独立的全局快捷键，激活已运行应用或启动未运行应用。
- 扫描 `/Applications`、`~/Applications`、系统应用目录；非标准位置可通过「添加应用」加入。
- 每个应用独立设置「面板中展示」；隐藏应用仍保留快捷键，可单独清除快捷键。
- 开启总开关并勾选应用后，单独按住 Option 约半秒展示提示面板，松开隐藏；提示面板不抢焦点，也可点击应用切换。
- 快捷键与剪贴板及其他应用冲突时保留旧配置；系统内部保留但未暴露冲突的快捷键仍可能无法响应。
- 没有展示项或关闭面板时停止检测；启用时每 0.1 秒检查修饰键状态，不记录按键内容，不需要辅助功能权限。
- 配置保存在应用的本机 UserDefaults 中。应用移动或卸载后可刷新列表重新配置或清除快捷键。

### 设置

通用、剪贴板、桌面背景、应用切换集中在同一窗口，支持中文/英文、跟随系统语言、登录时启动。使用分组卡片和悬停/按下反馈，动效遵循系统减少动态效果偏好。部分诊断信息尚未完整本地化。

## 构建与运行

需要 macOS 13+ 和 Apple Command Line Tools：

```sh
xcode-select --install
# 首次准备本地固定签名（--install 会导入钥匙串并仅信任代码签名）
bash scripts/setup-local-signing.sh --prepare
bash scripts/setup-local-signing.sh --install
bash scripts/build.sh
open 'dist/方寸.app'
```

构建脚本使用本机 Swift 编译器和固定证书签名，不下载第三方依赖。也可通过 `SIGNING_IDENTITY` 指定现有签名身份；首次签名迁移需要重新授权辅助功能，后续更新须复用同一证书。详见 [发布规则](RELEASING.md)。默认输出 `dist/方寸.app`；可用 `OUTPUT_APP` 指定输出路径。运行新版前先退出旧版。

```sh
OUTPUT_APP='.build/release/方寸.app' bash scripts/build.sh
```

## 名称迁移

中文名称「方寸」，英文名称「Tactora」。安装路径为 `~/Applications/方寸.app`，可执行文件为 `Tactora`。沿用原 bundle ID、数据目录和固定签名身份，已有剪贴板、背景和快捷键配置继续使用。历史发布包与提交记录保留原名称。

## 数据与权限

背景配置位于 `~/Library/Application Support/local.tango.macbglive/displays.json`，剪贴板数据也存于此应用的本地支持目录。背景转码缓存位于 `~/Library/Caches/local.tango.macbglive/video-v1/`。

- 原始背景文件不会修改；文件被移动或删除后需重新选择。
- 转码缓存目前不自动清理历史副本。
- 剪贴板记录可暂停，默认不会上传任何内容；无敏感标记的内容仍可能被记录。
- ad-hoc 签名会随重新编译变化，辅助功能授权可能需要重新添加当前应用。正式分发建议使用稳定的开发者签名。
- 开机启动默认关闭，通过 macOS 登录项服务注册。

## 目录

- `Sources/WallpaperCore`：背景配置、缓存、播放器和屏幕管理。
- `Sources/ToolCore`：剪贴板存储与搜索。
- `Sources/WallpaperApp`：菜单栏和 AppKit 界面。
- `Tests`：核心逻辑检查。
- `scripts`：构建、图标生成和界面测试。
- `Resources`：应用元数据。

应用快捷键可显示/隐藏应用（不是最小化）。通用设置支持独立启停桌面背景、剪贴板、应用切换；默认启用，关闭后隐藏入口、停用功能并保留配置。

Option 长按响应时间可在应用切换设置中调整为 0.10–5.00 秒，默认 0.45 秒，自动保存。

应用自动列表过滤无独立图标资源的应用；需要时可手动添加，已保存的应用配置继续保留。

Option 面板采用横向大图标、应用名和快捷键布局。已配置展示或快捷键的应用置顶，选中行后使用上移／下移调整顺序；顺序自动保存并同步到面板。

### 合盖降低内屏亮度

通用 → 合盖行为 →「合盖降低内屏亮度」。合盖前保存内屏亮度，合盖时降至最低，开盖、关闭功能或正常退出时恢复原值。保存值持久化，应用意外退出后再次启动可恢复；内屏离线或恢复失败时保留原值等待重试。仅调整物理内屏，镜像外屏也不受影响。

不再创建黑色遮罩，不修改系统休眠策略，也不保证最低亮度等于硬件断电。使用系统 DisplayServices 亮度接口（非公开 API）；接口不可用时不修改亮度。沿用原开关配置，以 IOKit 通知和每秒一次状态检查处理合盖。已在本机验证亮度归零与恢复；真实合盖/开盖流程需实机验收。

### 窗口管理

通过菜单或设置 → 窗口管理配置。默认 ⌃⌥⌘M 最大化，⌃⌥⌘←/→/↑/↓ 调整为左/右/上/下半屏；四角、居中、恢复原尺寸、系统全屏可自行绑定。点击快捷键直接录入，Esc 取消，Backspace 清除；配置自动保存并检查功能间冲突。通用功能开关关闭后注销快捷键并隐藏入口。

需要系统辅助功能权限；只操作当前应用的焦点窗口。最大化保留菜单栏和 Dock，不等同于创建系统全屏空间。部分应用有最小尺寸或不支持调整，操作结果受其限制。恢复记录仅存当前会话，最多 32 个窗口。

窗口权限排查：授权按钮会以当前 App 身份请求辅助功能权限。若更新后系统仍显示已开启但无法控制，需移除旧条目并重新添加固定安装路径。构建支持 `SIGNING_IDENTITY` 指定已有有效代码签名证书；未配置固定身份时构建会失败，避免跨版本授权失配。`bash scripts/test-window-manager.sh --installed` 验证实际安装 App 的默认快捷键，不使用测试进程代替 App 执行窗口操作。

窗口操作默认均使用 ⌃⌥⌘：M 最大化、方向键四向半屏、U/I/J/K 四角、C 居中、R 恢复、F 系统全屏、[/] 上一屏/下一屏。屏幕按桌面位置从左到右、同列从上到下排列并循环切换。跨屏保留大小和相对位置，较小屏幕会限制尺寸。每行包含布局示意与恢复默认键按钮；旧版已保存的绑定及清除状态保留，缺失的旧操作可逐项恢复默认。

### 防止休眠

菜单栏 → 防止休眠，或设置 → 防止休眠。预设 15/30 分钟、1/2/5 小时和直到手动停止；支持添加 1 分钟至 30 天的自定义时长（最多 30 个，可删除、自动保存）。添加时长不会自动启动，开始后显示剩余时间，可重新计时或随时停止。通用页关闭功能后结束当前会话并隐藏入口。

使用 macOS NoIdleSleep 电源断言，允许显示器息屏，不修改 pmset 系统配置、不影响合盖亮度控制。限时会话同时设置系统断言超时；到时、退出应用或停用功能时解除。重启应用不会恢复会话。该功能阻止空闲休眠，不承诺阻止合盖、手动休眠、低电量等系统强制休眠。

应用切换会在功能启用时统计普通应用进入前台的次数（包括 Dock、⌘Tab 和方寸），仅保存本机累计次数。可在应用切换设置中启用“按切换频次排列 Option 面板”；同频次沿用手动顺序，关闭恢复手动排列。悬停应用可查看次数。
